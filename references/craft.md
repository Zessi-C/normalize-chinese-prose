# 手法、语域与反例警戒

## 1. 经验感从哪来（这一节比动作库重要）

"没有毛病"和"像有经验的写作者写的"是两件事。把症状清零，得到的可能只是一段干净的空话。经验感有六个来源，改稿时按这六条往上加，不是往下删：

**一、具体到可核验。** 数字、版本、日期、路径、人名、机构、样本量。`性能有所提升` → `推理时间比基线快 3.4 倍（ZINC-2M，batch=32）`。原稿没给的具体项，进存疑清单向作者索取，**不许编**。这一条是经验感的地基：有经验的人手上总有数，没经验的人只有形容词。

**二、判断标强度。** 确证的直接陈述，倾向的用"多半／看起来／按这批数据"，存疑的写明"只有一条证据／还没验"。三种强度混着用，文章就有分寸（句式见 `models.md` 第 4 节）。全篇"显著""至关重要"等于没有强度信息；全篇"可能""或许"等于没有判断。

**三、承认边界与失败。** 有经验的人会写下没跑通的那次：`重跑十次没重现`、`第二批六个系统对不上码表，得人工核`、`这个结论只有单条轨迹撑着`。机器文本永远成功。留一处真实的失败或未知，比任何修辞都更像人写的。

**四、留取舍痕迹。** 说清为什么选 A 不选 B，代价是什么：`选 A 的前提是深度能保住，深度保不住，这笔钱白花`。只报结果不报取舍，是汇报腔，不是写作。

**五、要紧的先说。** 不是按时间顺序，不是按流程顺序，是按读者最想知道的顺序。第一句就给结论或给事实，背景往后放。鲁迅《秋夜》开头不交代时代，直接给后园和两株树。

**六、不替读者把话说完。** 每段末尾都收一句道理，就是过度点明。读者能自己补上的，删掉。收尾落在下一步动作、未解决的项、或具体代价上，不升华（`models.md` 第 4 节"收尾"）。

**六样分两档，不是所有文体都要凑齐。**

- **形式档（第五、六样）通用**：要紧的先说、不替读者把话说完。这两样靠重排与删减就能做到，任何文体都适用。
- **内容档（第一至四样）只适用于事实性论说文**（报告、论文、新闻、科普、公文、文案、讲稿、邮件、简历）：它们都要靠"原稿里有事实可补"才执行得了。
- **规范族豁免内容档**：合同、法规、说明书里没有"没跑通的那次"，也没有"取舍痕迹"——条款即事实。这类文本的经验感体现在**限定写得严密、情态用得准、边缘情形被封住**，不在这四样上。
- **虚构族豁免第一、三、四样**：小说的"具体"本属虚构，不许为了"可核验"去编细节。它的经验感体现在**细节是从场景里长出来的、人物有声音、情绪不由作者宣布**（见 `models.md` 6.2 虚构族三问）。

改稿时先问：这段属于哪一档？属于内容档而六样一样都没有，光删症状救不回来——得回去问作者要事实。属于规范族或虚构族，就别拿"至少两样"当失败信号，那是假警报。

## 2. 六个动作

改动只做句法、字法与语域，不做内容。

**拆**：前置修饰搬到句后，按小句推进。汉语的默认单位是流水小句（▽ 吕叔湘："一个小句接一个小句，很多地方可断可连"），不是带从属层级的长句。
> `这款刚刚落地的主打城市通勤的低成本国产自动驾驶系统` → `这款低成本国产自动驾驶系统，主打城市通勤，刚刚落地`
> `一个长得像你兄弟说话也有点像他的陌生男人` → `陌生男人，长得像你兄弟，说话也有点像他`（○ 余光中）
> （注：中心词孤立前置多用于叙事与论说；学术与公文若遇长限定，优先采用前置主谓重排或化为条件复句，避免正式主干松散悬空。）

**换**：万能动词＋抽象名词 → 本字动词；抽象名词主词 → 事件主词。
> `进行分析` → `分析`；`作出重大贡献` → `贡献很大`；`进行详细研究` → `详加研究`；`在老鼠身上进行试验` → `用老鼠试验`
> `他的收入的减少改变了他的生活方式` → `他因为收入减少而改变生活方式`（○ 余光中）

**删**：不增信息的壳。介词框架、能愿堆叠、成功副词、隐性名词、因果双标、冗余虚字。
> `对于……而言`、`关于……的问题`、`当……的时候`、`以便`、`从而`、`成功地推翻`、`不能忽视小众需求的存在`、`由于……使得……`
> 虚字层：`了`（十之五六可删）、`一些`、`某种`、`一定的`、`进行了`

**并**：三项并列降到两项；对举支架拆成两个短句；小标题不成对；**相邻两句别用同一套句法骨架**（逗号位置、成分顺序、收尾方式连着复现，就是填表感）。
> `一方面成本持续上涨，另一方面企业亟需拓展新客户` → `成本持续上涨，企业还得拓新客户`
> ⚠️ 打散的是**句法**，不是字数。**不许为了"看起来有起伏"调句长或拆段落**——长度分布测不出人机差别，这一项已从本技能撤销（`symptoms.md` G 节第 10 条）。旧版这里写的"段落厚薄不齐"同批撤掉。
> 示范（三句同一套"这个版本＋动词＋宾语"）：`这个版本修掉了超时问题。这个版本也降下了内存占用。这个版本还补上了缺失的日志。` → `这个版本修掉了超时问题，内存占用也下来了；缺失的日志是最后补上的。`——**只换第三句的骨架，三条事实一条不少、一条不加。**

**主**：非必要被动还原为主动或无标记句。
> `他被怀疑偷东西` → `他有偷东西的嫌疑`；`他被选为议长` → `他当选议长`；`不会被你这句话吓倒` → `你这句话吓不倒我`（○ 余光中）
> `阵列在每次重跑中均被漏检` → `阵列每次重跑都漏掉`

**缀**：让限定成分落回它该在的位置，一"的"一义。
> `有不洁的颜色的都市的河沟` → `都市的脏河沟`；`具有很高的知名度` → `很有名`；`可读性颇高` → `好看`（○ 余光中）
> `两项结论具有普遍适用性` → `两项结论普遍适用`

**正**（正面界定替代负描述）：非必要不立反面。删掉机械防守与虚设假想敌，把“不做什么”收敛为“正面做什么”。
> `本方案不进行全面的系统重构，也不替代现有流程，而是聚焦于三个核心接口的优化` → `本方案聚焦优化三个核心接口。`（删掉两个空转假想敌，直接陈述正向动作）
> `这并不意味着旧架构存在根本缺陷，更不代表可以忽视历史负担` → `旧架构在低并发下依然稳定；本次改造旨在支持万级并发。`（将避险对冲落实为两造客观事实）
> `新流程不仅没有增加审批耗时，反而简化了交接链路` → `新流程简化了交接链路，审批耗时也未增加。`（化解“不仅没有……反而”的表演感）
> ⚠️ **文体除外线**：法规、合同的法定除外条款（`不适用……情形`、`甲方不承担……责任`）与技术规范的硬性边界（`不支持热插拔`）属于定义标的与责任切割，**严格保留，不得删改**。

**正式感从哪来：音节配双。** 这不是本机断言，是教材成文的改法理由——△ 港中大 ILC 教材把「物質上的需求」简化为「物質需求」，给出的理由是"與『生活水平』組成**二二節奏**的並列句式，使文句更精練和工整"；改「例行性檢查」为「例行檢查」，理由是"雙音節『例行』配雙音節『檢查』，簡潔又好讀"（`cases.md` 第 1 节）。**双音节配双音节、二二成对，句子自己就站住了**——庄重在这里，不在多层"的"和被动式里。

高频欧化框架的直接替换（做英译往返测试时，这几式最先现形）：

> ⚠️ **规范族（合同/法规）与严肃技术文档慎用此表**：涉及法定生效条件（如`在 X 的情况下`）与法定标准用词（如`以 X 为准`）时保持严密，不作机械通俗化替换。

| 原式 | 改法 |
|---|---|
| `在 X 的情况下` | `X 时`／直接写成条件句 |
| `使得 X 变成 Y` | 让 X 自己作主语：`X 变成 Y` |
| `对 X 进行检查` | `检查 X`（公文固定搭配可留，同一篇别连用三次） |
| `加以说明／予以批准` | `说明／批准` |
| `随着 X 的不断增加` | `X 越来越多，……` |
| `以 X 为 Y` | `把 X 当作 Y`／`X 就是 Y` |
| `一种……的方式／过程` | 直接说那个动作 |
| `X 以及 Y，Z` | 拆成两句，或改用顿号并列 |
| `等等` | `等`（汉语不用 etc. 的重叠式） |
| `存在……问题` | `有……问题`／直接说出问题是什么 |
| `通过……的方式` | 直接说那个动作 |
| `在……方面／层面上` | 换具体主语＋动词 |
| `不仅没有 X，反而 Y` | 优先肯定句：`落实了 Y，且未增加 X` |
| `这并不意味着 X，更不代表 Y` | 直接陈述正面事实与适用范围；删除凭空设立的假想敌 |
| `不追求 X，也不试图 Y，而是聚焦于 Z` | 直接正面陈述：`聚焦于 Z`（删除前置否定） |

## 3. 先定语域，再动句子

分不清该往哪个方向改，先问四件事。这四问决定句法余量，比任何规则表都管用：

1. **谁读？** 专家、上级、普通读者、还是三个月后的自己。读者越外行，前置修饰越要搬到句后，术语越要给一句白话。
2. **在哪读？** 纸上／屏幕上可以回读，讲稿和口播不能回读；手机上是跳读，长段落必死；合同要经得起逐字抠。
3. **读完要干什么？** 做决定、照着操作、被说服、还是只是知道一下。要照着操作的，步骤必须能一眼数清；要做决定的，代价必须写在前面。
4. **这是哪一变体的书面语？** 大陆普通话、台港澳、还是海外华语。△ 刁晏斌《百年现代汉语发展的回顾与前瞻》（《北京师范大学学报》2023 年第 2 期，仅摘要页）把百年现代汉语分成"普通话、台港澳国语与海外华语三条发展线索"，趋势是"趋同与存异"。**港式、台式书面语的长定语与被动式密度本来就更高，那是变体差异，不是病**——按大陆语感去"顺"港稿或外资合规文件，会系统性改错。判"不改"，变体差异不是病。
   https://wkxb.bnu.edu.cn/CN/abstract/abstract486.shtml

四问答完，语域基本定了。下面这张表是分族的具体差别——**它不是豁免条款，语域决定"怎么改"，不决定"改不改"**。

### 平台合规族（政府与公共服务网站、政务 App、面向公众的界面文案与提示语）

- **这一族的文字层优先级高于语体优化。** ◎《国家通用语言文字法》2025 年修订第十七条把"信息处理和信息技术产品以及政府主办的或者提供社会公共服务的门户网站、移动应用程序等互联网信息平台"纳入"应当符合国家的规范和标准"，第四章设法律责任（责令改正、警告、通报批评、对主管人员处分）。**这是 2026-01-01 起生效的法定义务，不是建议。**
- **外文与字母词**：第十二条要求"需要使用外国语言文字的，应当用国家通用语言文字作必要的注释"。**落点是加注，不是禁用**——术语原形保留（信息守恒），首次出现补中文注释（合规）。
- **界面文案的语体**：短、动作明确、不堆限定；这与技术族一致。但**别把法定名称、机构全称、政策专名改写成"更顺"的说法**（`norms.md` 1.1）。
- **底线**：繁异体只在第十九条豁免清单内可用；用字以《通用规范汉字表》为准。

### 规范族（公文、法规、规章、合同、司法与行政执法文书、病历、知情同意书、说明书、招标文件、标准文本）

- **读者与场景**：上级、相对人、执法与司法场合、患者与用户；要经得起逐字抠，会被反复回读，也可能被拿去打官司。
- **长定语**：限定性长定语**保留**。拆之前先问一句：**这个限定是在定义义务标的，还是在追加一项要求？** 定义标的的（`由税务机关出具的、载明上一年度应纳税所得额的完税证明原件`）一旦拆成两句，定义就变成了一项独立义务，法律效果跟着变——这种只能重排，不能拆义。`凡……的，应当……` 是正当结构。
- **被动**：`应当／不得／经……批准` 体系不动。带施事的被动（`由……出具`）是正当的，它标的是义务主体，不是欧化。
- **名词化**：术语性名词保留（`可扩展性` 是术语，`具有可行性` 不是）。
- **防御性冗余不是同义反复**：合同里把一种情形说两遍，常常是为了封住两种解释。删之前先问"删掉会不会多出一种解释"。
- **版面**：序次语、六角括号严格按 GB/T 15834；`国发〔2011〕3 号`。
- **自查**：不用 `models.md` 的正向七问（其中第 3、5、6、7 问在这类文体上会给出错误甚至危险的答案），改用 `models.md` 6.2 的**规范族三问**。
- **最容易犯的错**：把庄重误当欧化，删掉必要限定，导致条文出现歧义。**改这类文本，宁可判不改。**
- **底线**：数字、用字、标点全按国标；责任主体、情态动词、范围量词逐字守恒。

### 学术族（论文、综述、学位论文、基金申请、审稿意见）

- **读者与场景**：同行；会跳读摘要与图表，会逐字抠方法与结论。
- **长定语**：每句只嵌一层；定义句可留。
- **被动**：方法描述里可留（`样本被分成两组` 是惯例），结论别用"被认为"。
- **名词化**：术语不动，伪名词化（`具有可行性`、`实现了提升`）要治。
- **元话语**：删 `值得注意的是` 一类，但允许 `本节讨论`、`如前所述` 这类真实的路标。
- **版面**：图表注、单位、百分数范围硬规范；有效位数不截尾。
- **最容易犯的错**：一是把术语改成大白话（`6-mer` → `六碱基`，可检索性归零）；二是**把证据强度顺手拔高**（`可能` → `显著`）。
- **底线**：英文专名与原符号不许意译；强度标签守恒。

### 技术族（README、API 文档、运维手册、变更日志、代码注释、commit message）

- **读者与场景**：赶时间的工程师，屏幕上跳读，常常一边报错一边查。
- **句式**：动词开头，一句一件事。`把单细胞原始数据跑成表达矩阵`，不是 `该工具是一个用于……的封装`。
- **具体项**：版本号、路径、命令、环境变量、错误码写全。`确保已正确安装相关依赖` 是废话——要写 `Python 3.10+ 和 STAR 2.7.11 在 PATH 里，否则会静默跳过比对`。
- **被动**：几乎不用。`配置文件被读取` → `程序读配置文件`。
- **代码注释**：写"为什么"，不写"是什么"。代码自己说明它做了什么。
- **commit message**：祈使句起头，一行说清一件事。
- **最容易犯的错**：把文档写成宣传文案（`强大的`、`灵活的`、`开箱即用`）。
- **底线**：命令能直接复制执行；版本与平台写清楚。

### 传播族（新闻消息、深度报道、科普、公众号、产品文案）

- **读者与场景**：不认识你的人，手机上跳读，三秒决定要不要往下看。
- **起句**：第一句给事实或给结论，不给背景板。`某市 9 月 28 日开会定了三件事`，不是 `近日，某市举行了关于……的重要会议`。
- **长定语**：拆到最短。前置修饰必须搬后。
- **引语**：原样保留，不改写成书面语。
- **具体项**：谁、什么时候、多少钱、多少人。`强调`、`指出` 后面的空话全删，换成会议**实际决定的事**。
- **黑话**：`赋能／抓手／闭环／打造生态／全方位解决方案` 一律删干净——不是换个说法，是这些词根本不承载信息。
- **最容易犯的错**：为了"有温度"补抒情。传播族的温度来自具体的人和数字，不来自形容词。
- **底线**：事实与归属不能含糊化；不为了好看改数字。

### 口语族（讲稿、答辩、口播、播客稿、汇报）

- **读者与场景**：听众，**无法回读**，一遍过。
- **硬约束**：一句一口气念得完。前置修饰必须搬到句后，否则听众听到中心词时已经忘了修饰语。
- **衔接**：靠停顿和副词（就、才、却、还是），不靠"从而""因此"。
- **列举**：三项以上用口语排开（`一个是……另一个是……再一个是……`），不用"首先其次最后"。
- **数字**：写阿拉伯数字，但要念得顺。`50,000 reads/cell` 念出来是什么，先自己读一遍。
- **最容易犯的错**：把书面稿直接拿去念。书面稿的长句在纸上没问题，在空气里散架。
- **底线**：每段一个信息点；不喊意义。

### 私人族（邮件、即时消息、简历、申请文书、随笔、散文、小说）

- **邮件与 IM**：第一句说要对方做什么。段落短到手机上不用滚。主题行写实事。
- **简历与申请文书**：动词开头，一条一件事，带结果与数量。`负责数据治理工作` → `统一 37 个业务系统的数据口径，跨部门取数从半天缩到两百毫秒`。**不写"具备较强的沟通能力"**——那是空话，改成一件能核验的事。
- **随笔、散文、小说**：语域最宽，可断可连，句子长短自然会有出入——**那是作者呼吸与内容的结果，不是我们要造出来的东西**（贾平凹说句长以呼吸为准，且反对故意追求短句或长句）。忌成语套话（`时光荏苒`）、忌形容词堆叠、忌升华收尾。鲁迅"有真意，去粉饰，少做作，勿卖弄"四条正好用在这里。
- **硬规则（先判有意，再判毛病）**：文学语言的偏离、方言写法、个人语体，一律**先假定作者有意**，进存疑清单向作者确认，不得默认是病症。△ 萧乾《我看文学语言规范化》（《语文建设》1992 年第 4 期）："从文学角度来说，我不赞成规范化……规范化的文学语言有时就成白开水了。"△ 贾平凹："有人故意追求短句或长句，首先就不符合人体结构"，句长以呼吸为准。△ 金宇澄（南都 2024-07-29）：《繁花》的"不响"用普通话写作"我一辈子不可能写这两个字"——**方言不是不规范，是另一套语体的母语**。△ 莫言（中国作家网 2018-08-15）：方言入文应当"驯化"，而"有些作家说自己的语言受到了外国作家的影响，实际上是受了中国翻译家的影响"。见 `norms.md` 2.7。
- **最容易犯的错**：给私人写作套公文骨架（`关于……的情况说明`），或者给散文加"综上所述"；其次是**把偏离改成光滑**（`symptoms.md` G 节第 9 条）。
- **底线**：不伪造亲历，不替作者编他没写的事。

### 译文族（翻译文本、双语对照、译著、字幕）

- **先判它是不是译文——这一步不能跳。** 一句读着像翻译腔，有两种可能：它本来就是译文（默认不改），或者是中国人自己写的欧化句（按欧化轴改）。判法：① 有没有原文对照、出处是不是译著或引进版；② 问作者。两者都拿不到时，**按最小改动处理，并在交付里写明"这一处的改法取决于文本身份：若是译文请回退"**。理由是代价不对称——改坏译文损害的是忠实，留着翻译腔损害的只是顺畅，前者更重。
- **这一族默认不改，且有学科依据。** 翻译学界的研究把现代汉语书面语的基线本身算作翻译的产物：△ 朱一凡《翻译与现代汉语的变迁（1905—1936）》（华东师大博士论文，导师潘文国，2009；后成书商务印书馆，**仅摘要页**）称"这一时期在翻译影响下建立起的现代汉语，**决定了以后几十年间流行于知识界的现代汉语书面语的基本面貌**"；△ 王伟《现代汉语欧化与翻译策略之综合研究》（上海交大博士论文，2008，**元数据级**）把欧化归入语言接触与"归化／异化／语言规化"的框架。**所以"这是译文，默认不改"不是本机的偏好，是有学科立场的：**欧化不只是一种语言层现象，它同时是翻译策略的产物。
- 另一层依据是作家语感——△ 王小波《我的师承》："但是最好的，还是诗人们的译笔；是他们发现了现代汉语的韵律。"现代汉语的精密有一部分正是好译笔带来的（`norms.md` 2.4、3.2）。
- **要改的只有一种**：译者自己也没读懂原文而写出的不通句。判据是 ◎ 陈雪引的"不通、不简、不洁"里的**不通**——中文读不下去，而不是"像英语"。
- **不许改的**：为忠实而保留的原语序、长限定、被动、抽象名词。△ "但是翻译却宁可忠实而不顺"——此句只见朱自清《鲁迅先生的中国语文观》（1946）记述，朱自注明言"恕不一一加引号"，**鲁迅原篇未核到**，引用时标转引（见 `norms.md` 第 6 节第 10 条）——那是译者本人的选择，改稿的人无权替他选。
- **自查**：不用正向七问，用**回读测试**（这一句中文能不能一遍读懂）加**术语与原语对照一致性**。
- **底线**：术语前后一致；引文出处、页码、专有名词原形守恒；双语对照不改动源语一侧。

### 附属族（图表标题、图注、表格、脚注、目录、摘要框）

- 图表标题是名词短语，不是句子：`三种平台的基因检出率对比`，末尾不用句号（GB/T 15834 A.1：图表短语式说明中间可用逗号，末尾不用句号）。
- 图注可以长，但要能被单独读懂——不看正文也知道这张图在说什么。
- 表格里的字越短越好，长限定搬到表注。
- 脚注承担出处与例外，不承担正文该说的论证。

### 遇到九族都不像的文本：五步程序

`examples.md` 给了十三类的 Before/After，比上面九族更细。碰上十三类之外的，按这五步走：

1. **找最近的族。** 九族里挑一个最像的，按那一族的底线走。
2. **问四件事。** 谁读、在哪读（能不能回读）、读完要干什么、这是哪一变体的书面语。语域由此定。
3. **找一篇这个类型里公认的好文本，读三段。** 记下它的起句方式、相邻句怎么换骨架、判断落在哪一句、怎么收尾。**先去 `samples.md` 找**（26 段分六语体，逐字一手），那里没有再上网找；网上也找不到就用相近类型的。**这一步不能省**——没有目标形状，改出来的只能是"没毛病的稿子"，不是"有人写的稿子"。**但只学它的句式与推进，不学它的长短配比**（`symptoms.md` G 节第 10 条）。
4. **先改一句试。** 改完拿它跟第 3 步那篇比，读着突兀就回退，不要一路改到底再回头看。
5. **保守优先。** 法律、医学、金融、合同、监管报送、药品说明、招标文件，第一要务是无歧义与可追责，不是好读。宁可不改，把疑处列进存疑清单。改坏了要出事，改平了顶多不好看。

## 4. 反开脱五问

想以"这是公文／学术文体，得庄重"为由保留一处欧化结构，先过五问。答不出"是"就改；答得出，把理由写进改动说明，不要默默留着。**第 1 问与第 5 问最要紧，两问答不出就别留。**

**这与 SKILL.md 工作流程第 1 步"拿不准判不改"不矛盾，两者管的层次不同**：

- **段落级**（这段该不该动）走履职判据——这段在这个文体里履职了吗？拿不准就判不改，规范族与虚构族尤其如此。
- **结构级**（这一处欧化壳该不该留）走反开脱五问——已经认定要改的段落里，某一处想留下，就得答出它承载什么信息，答不出就改。

顺序是先段落后结构。**不要用结构级的"答不出就改"去推翻段落级的"判不改"**——那正是把合同条款拆坏的来路。**注意**：反开脱五问用于审视那些“伪装成庄重但实无信息”的空转壳，严禁用于裁决规范族的法定表述、定义标的限定与专业术语。

1. **去掉这层限定，句子少了什么信息？** 说不出具体信息，就删。反面参照：◎ 邓小平 1975 年"建成一个独立的比较完整的工业体系和国民经济体系"——连用两个"的"，**每一个都在缩小范围，删任何一个都改变所指**。这种句子要留，依据不是"它是公文"，是它承载信息（全段见 `samples.md` 4.2）。
2. **这个被动句的施事能不能补出来？** 能补就补成主动；补不出来才留被动，并在存疑清单里写明施事缺失。
3. **这个名词化换回动词，会不会损失术语精度？** 会损失才留（`可扩展性` 是术语，`具有可行性` 不是）。
4. **这个写法是不是已经沉淀进现代汉语了？** 优秀的当代作者也在用、读者不会觉得别扭的，不必强改（判据见 `norms.md` 2.2、2.3）。**反过来**：只有翻译腔文本里才见得到、母语作者自己不会这么写的，就改。
5. **按中文习惯，有没有同样精确又有力的说法？** 这一问是准入条件，来自 △ 朱光潜（《朱光潜全集》第四卷，安徽教育出版社 1987，转引）：「**如果一句话依中文习惯可以说得同样精确有力，我们就绝对不能欧化它；欧化须在表现上有绝对必要时才可采用**。」
   它比第 1 问更严，也更可操作：第 1 问查"这层限定有没有信息"，第 5 问查"**换个说法，信息会不会丢**"。答得出"换成就说不清了"，才留得住——◎ 鲁迅给的正是这个理由：要说得精密，固有的白话不够用，才只得采些外国的句法，"**補這缺點的是精密**"（《玩笑只當牠玩笑（上）》，1934）。**没有换来精密的难懂，两头都亏。**
   出处与全部保留条件见 `cases.md` 第 6 节。

公文固定搭配（`对……进行检查`、`予以批准`、`作出突出贡献`、`具备……能力`）不必逐一强拆，判据是频次：频密套用时是套式而不是必要，照减。

## 5. 改稿的态度

这一节讲的是劲道，不是技巧。

> ◎ 写完后至少看两遍，竭力将可有可无的字，句，段删去，毫不可惜。宁可将可作小说的材料缩成 Sketch，决不将 Sketch 材料拉成小说。（鲁迅《答北斗杂志社问》第四条）

后半句最容易被忽略：**宁可缩短，决不拉长。** 改写里几乎所有"加一点让它更顺"的冲动，方向都是错的。扩写几乎总是变成废话，压缩才是允许的方向。

> ◎ 写完了一篇必须删改。不要溺爱自己的文字！（老舍《我怎样学习语言》）
> ◎ 我们写作，最容易犯的毛病是写的太多。谁也不能既写得多，而又句句妥当。（同上）
> ◎ 我不单不轻易用个形容词，就是"然而"与"所以"什么的也能少用就少用，为是教文字结实有力。（同上）
> ▽ 字要改，句要改，连标点都要改。（同上）

"对自己宽大便是对读者不负责"——老舍这句是改稿的立场。对原稿客气，改出来的东西就还是原稿。

**但狠劲只用在自己的话上，不用在原稿的事实上。** 数字、专名、引文、证据强度一个不能动（见第 7 节反例警戒 3、4）。删的是壳，不是骨头。

## 6. 常态文本读起来什么样（对照用，不是标准）

对照过两类真实文本，得到一个印象，写在这里供你读的时候参照，不要拿去量化。

**法规条文**（《国家通用语言文字法》通读）。庄重靠的是词和句式骨架：`应当`、`不得`、`经……批准`、`凡……的`，加双音动词和整齐的条款序号。句子可以很长，长在一串并列限定和分号上，不长在多层"的"套多层"的"上；全篇被动式极少，因为条文写的是谁该做什么。读完的感受是：条款不用回读第二遍才知道主语是谁。

**名家论述文**（余光中《怎样改进英式中文》1987、老舍《我怎样学习语言》1951）。小句短，衔接靠语义而不是关联词，句子长短差别很大——一句二十几字铺开来，下一句五个字收住。老舍那段是现成的样子：前半「我不单不轻易用个形容词，就是『然而』与『所以』什么的也能少用就少用，为是教文字结实有力」二十几字一路铺开，落点压在「结实有力」四个字上；紧接一句「不要溺爱自己的文字！」只有七个字。

⚠️ 读这段要读对因果：**是内容和语气造成了这两个句子的长短**——前一句在铺陈一条做法，后一句在喝住自己。本技能在 2026-10-01 以前把它写成了操作项（"铺开的长句后面要跟一句短的收住"），那是把观察当配方，已撤（`symptoms.md` G 节第 10 条）。**照这个比例去配句子，得到的是仿制品的节奏，不是节奏。**

**为什么对照样本只取 1949 年以后**：1920—1930 年代的白话还在形成期，名家句法里刻意实验的成分重，而且这批人多是**自觉的欧化主张者**——◎ 鲁迅：「但是翻译却宁可忠实而不顺」。他们的**写作主张**照用，句子不作节奏样板。详见 `models.md` 第 0 节。

对照的意义只有一个：**当你犹豫某句要不要改时，先想"这一句放进法规条文，或放进一篇 1980 年以后的当代论述文里，读着突兀吗"**，而不是想它有没有命中某个格式。突兀就改，不突兀就留。

## 7. 反例警戒

1. **不加装饰。** 不补抒情句、道德评点、"值得深思／须记取"一类收尾；不为"像人"塞"我觉得""有意思的是"。模仿的是句法与语域，不是套一层外壳。
2. **不制造电报体。** 实证研究显示模型的句子本来就偏短、层级偏浅（▽ 吴继峰等，《语言文字应用》2025 年第 4 期；**该研究没测句长方差，旧版此处"长度偏齐"四字是本机归纳挂在了研究名下，已删**——长度分布的撤销理由见 `symptoms.md` G 节第 10 条）；把长句一律切成八字以内短句，等于换上第二种模板，而且必然顺手丢掉限定信息。**但反过来也不成立**：不能为了让稿子"有起伏"去人为拉长句子、拆段落、调配长短。这一条管的始终是**别削平信息**，不是句长配比。目标是**小句自然衔接、该长的让它长**——长短是结果的描述，不是操作项。这条不松动去欧化的主轴：拆嵌套、还原被动、去名词化照做。
3. **不升级证据强度。** `可能／据称／推测` 不得改成 `明显／证明／必然`；`[推断]` 不得写成 `[已发表]`。
4. **不动标识符与专名。** DOI、PMID、arXiv 号、参数名、英文术语原形、单位符号照原样；不要把 `ms` 写成毫秒、`24 个月` 写成两年——汉字数词没法核对，术语意译过来就再也搜不回去。
5. **不重复表意。** 同一件事讲两遍不算"加强"。老舍："谁也不能既写得多，而又句句妥当。"
6. **不伪造。** 不添亲历、不补来源、不把相关说成因果；原稿缺主语、缺依据的地方列进存疑清单，不要用流畅掩盖。
7. **不去书面化。** 别把"两项／三项／不经组装／其定位是"写成"两条／三个／别用／开不开／下场"。语域跟原稿走。这条在实际改稿里最容易破——一顺手就滑向口语，本机曾在一份 6904 字的文献报告上滑掉 39 处，逐条回改。
8. **不照降重网站的替换表改。** 那些词表是检测器营销，不是写作规范（见 `symptoms.md` G 节第 6、7 条）。本技能不承诺降低 AIGC 检测率。
9. **不把规范文体误当 AI 味。** 公文与学术汉语本来就该低变异、少抒情、多限定。判据是这段有没有承载信息与判断，不是它像不像模板。
10. **不把职业美德当症状。** 合同的防御性冗余像同义反复，法律的长限定像欧化，小说的刻意含蓄像零具体，学术的克制像无判断落点，译文的欧化是它的母语。**判据分两层，先问履职、再问像不像好中文**（SKILL.md 立场）。这是本技能最容易犯、后果也最重的错：切掉的不是毛病，是这段文本赖以成立的东西。
11. **不把"改得漂亮"当成功。** 补了原稿没有的事实、升了证据强度、替作者编了细节，哪怕读起来好得多，也是失败（第 8 节样例）。
12. **不立假想敌、不滥用负描述。** 严禁为了“显得中庸周全”而凭空添加`本方案不追求……也不试图……`或`这并不代表……`。非必要不立反面，直接给出正面断言。只有在读者极易产生重大误解或属于法规合同的法定除外条款时，才使用否定界定。

## 8. 一个完整样例（欧化＋AI 味 → 常态）

**原稿**
> 随着人工智能技术的不断深入发展，在当前的产业背景下，这款刚刚落地的主打城市通勤的低成本国产自动驾驶系统，被认为具有显著的安全性和较高的市场认可度。值得注意的是，该系统不仅能够实现复杂路况下的自主决策，而且能够有效降低运营成本，更重要的是，其为后续的数据闭环提供了有力支撑。首先，通过对行业数据的分析，团队实现了算法的持续优化；其次，模型的迭代速度得到了明显提升；最后，用户的使用体验也作出了重要改善。综上所述，这一创新实践对于整个行业而言，都具有深远的影响和重要的参考价值。

**改稿**（只动句法、字法与语域，不补原稿没有的东西）
> 这套自动驾驶系统刚落地，主打城市通勤，成本低。据团队介绍，复杂路况下它能自主决策，运营成本有所下降，跑出来的数据可以回流给下一轮训练。团队分析了行业数据，算法持续优化，模型迭代速度有所提升。

**必须随稿交出的存疑项**（原文没给，改稿不许补造）
- "被认为具有显著的安全性"：判断主体是谁？量化依据是什么？
- "较高的市场认可度"：保有量、复购、评分，哪一项？
- "使用体验作出重要改善"：改了什么指标，改善幅度多少？
- 末句"具有深远的影响和重要的参考价值"属无信息结论，已删；若作者要保留观点，请他写明影响的是哪一环。

**这处改稿刻意做得不好看，因为它只能做到这一步。** 原稿通篇没有判断主体、没有一个数字、没有一项指标，三条硬规则把改法封死了：

- `被认为具有显著的安全性`——施事缺失，只能用 `据团队介绍` 这类不升格的写法顶住，**不能自己补一个主体**；
- `能够有效降低运营成本`——"有效"是无据强调，删掉它、保留 `有所下降`，**不能改成 `运营成本降下来`**，那是强度升格（第 7 节警戒 3）；
- `使用体验也作出了重要改善`——原稿没给指标，**不能写成 `用户坐上去也觉得稳`**，那是添了原稿没有的感知事实（警戒 6）。

旧版本的改稿恰恰犯了这三条（`运营成本降下来`、`它自己拿主意`、`用户坐上去也觉得稳`），读起来漂亮，其实是把空话换成了没有出处的具体话，**比原稿更危险**。记这一条：**改得漂亮但补了原稿没有的东西，是失败，不是成功。**

另一处不够：删掉的全是壳，**没有一处补上经验感**——第 1 节六样一样都没加。真正的改法是先向作者要三样东西：安全性的量化依据、市场认可度指的是哪一项、迭代速度提升多少。要到之前，这段只能停在"干净的半成品"，并在交付说明里写明它缺什么。
