# 病例与成文改法（带出处）

## 0. 这份文件的用处，以及它补的是什么洞

`symptoms.md` 给的是症状分类，`craft.md` 第 2 节给的是六个动作。这两处过去有一个共同的软肋：**改法大多出自余光中一个人的判断，或本机自撰**。用户质疑"你凭什么说这是病"时，我拿不出第二方。

这份文件补的就是这个：**每一例都带一个机构或署名作者的成文改法与改法理由**。三档来源——高校写作教材（香港中文大学中国语言学习中心 ILC）、报刊语文专栏（香港《文汇报》"恒大清思"，作者为中文系副教授／高级讲师）、CSSCI 类期刊论文全文（《上海理工大学学报（社会科学版）》2019）。

置信标记沿用 `models.md` 第 0 节。第 5 节的量化证据与第 6 节的反面意见同样重要——**它们决定这份病例清单哪里可以硬，哪里必须软**。

## 1. 学生自撰病例（ILC 教材，一手）

这批最有用，因为句子是**学生自己写的中文，不是译文**——正好打在主轴上：欧化不是翻译文体的专利，是当代书面汉语的通病。

来源：©2010 香港中文大学自學中心／中国语言学习中心，"ILC 論文寫作"在线教材〈歐化句子〉（一）至（四），高校机构页＋自学 PDF＋练习答案。
（一）濫用「被字句」 https://www.ilc.cuhk.edu.hk/chinese/AWOnline/engstyle1.html
（二）濫用後綴「性」 https://www.ilc.cuhk.edu.hk/chinese/AWOnline/engstyle2.html
（三）濫用「一+量詞」 https://www.ilc.cuhk.edu.hk/chinese/AWOnline/engstyle3.html
（四）濫用繫詞「是」 https://www.ilc.cuhk.edu.hk/chinese/AWOnline/engstyle4.html

### 被字句

| 病例 | 成文改法 | 该教材给的理由 |
|---|---|---|
| 他被人救起了 | 他獲救了 | 被字句传统带不如意色彩，正面语义不该用 |
| 他被老師表揚了 | 他得到老師表揚 | 同上 |
| 政府的施政方案被市民支持 | 判为不宜 | **只听到前半会以为是"被批评"**——被字句自带负面预期，语义歧义 |
| 物質上的需求很快地被滿足 | 物質需求也得到即時的滿足 | 去被动＋简化"X 上的"赘饰 |
| 雖然天賦人權的說法難以被驗證 | 難以驗證（删"被"） | "難以驗證／難以接受／難以相信"是固定格式，"以"后不能加"被" |
| Faraday's disk 這裝置已被改良不少 | 已改良了不少 | **受事死物作主语，靠语意表被动**，如"水喝完了" |

### 后缀"性"与名词化

| 病例 | 成文改法 | 理由 |
|---|---|---|
| 這本書可讀性很高 | 這本書很耐讀 | 名词化包装 |
| 病人要做例行性檢查 | 病人要做例行檢查 | "雙音節『例行』配雙音節『檢查』，簡潔又好讀" |
| 第二部分則評論他們的觀點於現今香港社會之有效性 | 評論他們的觀點是否適用於現今香港社會 | "有效性"文意不明；"有效"不能修饰"观点"；"于……之……"框架 |
| 盧梭最基本的假設是人生而平等自由。他以此來抨擊奴隸制的合理性。 | 盧梭深信人生而平等自由，並據此信念抨擊奴隸制 | **抽象名词不能施行"抨击"**——主语必须是能做事的 |
| 馬克思認為人藉著行動所得成果探索行動的意義和有效性。 | 改"有效性"为"果效"、删"行動所得" | 前面用双音节"意義"，后面最好也用双音节 |

### 一＋量词

| 病例 | 改法 | 理由 |
|---|---|---|
| 一樣物件的存在必須對周圍的環境帶來影響的。 | 物件的存在必然對周圍的環境帶來影響。 | 集体概念前不加数量词；句尾"的"表"已知／已然"，误用（该教材引金立鑫 2006:46–61）；"必须"与"必然"混用 |
| ……有一個同學跟我提出了一樣的觀點 | 有同學提出了跟我一樣的觀點 | "没有需要强调『一個』" |
| 作為一個有文化的大學生，我們都要懂得怎樣運用科學知識改善生活 | 作為大學生，我們都要…… | 后面用复数"我們"，前面就不该用"一個" |

### 系词"是"

形容词可直接作谓语："他很聰明"不必写成"他是很聪明的"（该教材对照 He is very clever 指出这是照搬英语骨架）。同页另列"是"的五种正当用法——**判据是能不能删，不是它出现了没有**。

### ★ 这份教材最有价值的一句

改"物質上的需求"为"物質需求"时，ILC 写的理由是：簡化後可"與『生活水平』組成**二二節奏**的並列句式，使文句更精練和工整"。

这一句替本技能解决了一个老问题。我一直主张"正式感来自音节与选词，不来自英语化句法"（`norms.md` 3.1 冯胜利条），但那是我方的断言。**现在有一个教学机构在成文教材里，把同一件事当作修改理由写给学生看**。改稿时可以照这个路子说理：不是"这样更雅"，是双音节配双音节、二二成对，句子自己就站住了。

## 2. 名词成灾与万能动词（《文汇报》"恒大清思"，陈洁珊，一手）

来源：陈洁珊（香港恒生大学中文系高级讲师）《【恒大清思】字詞搭配應講究 優化深化莫濫用》，《香港文匯報》2021-06-16
https://www.wenweipo.com/a/202106/16/AP60c90f54e4b08d3407c68a8a.html
作者明确说这批病例就是余光中所说"名词成灾""伪术语"。

| 病例 | 改法 | 毛病 |
|---|---|---|
| 這本小說的可讀性很高 | 這本小說值得一讀；再进一步：令人愛不釋手 | 名词化＋形容词只剩"高／低"两档 |
| 這單位的實用性很高 | 這單位的間隔很實用 | 名词化 |
| 他是知名度很高的鋼琴家 | 他是著名鋼琴家／蜚聲國際的鋼琴家 | "度"字名词化＋选词贫乏 |
| 香港是國際化城市 | 香港是國際城市 | "化"后缀滥用 |
| 國際性盛事 | 國際盛事 | "性"后缀滥用 |
| **『全港教育研討會』豈同於『全港性教育研討會』** | 删"性" | **后缀"性"会造成歧义** |
| 優化商場設施／優化環境的措施／優化系統設計／優化公司的營運效益 | 改善／改良／提高 | 万能动词（作者称其"百搭"） |
| 深化研究／深化兩地合作／深化兩國文化交流 | 深入研究／加強／促進或加強 | 万能动词＋抽象名词 |

**最该记住的一例是"全港性教育研讨会"**。它说明后缀滥用不只是不雅观——**它会读错**。"全港教育研讨会"是全国范围的教育研讨会，"全港性教育研讨会"字面上成了另一种性质的教育。欧化成分有时付的是歧义的代价，不是文体的代价。这类病例在 `craft.md` 反开脱五问里属于"删掉不会少信息，加上反而多出误读"，不该保留。

同一作者也划了界：**"現代化""工業化""全球化"这类译入术语"實難以避免"**——与 `norms.md` 2.3 的沉淀判断一致。后缀不是病，无信息地挂后缀才是病。

## 3. 介词框架吞掉主语（《文汇报》"恒大清思"，陈美亚，一手）

来源：陈美亚（香港恒生大学中文系副教授）《【恒大清思】歐化句雖然彆扭 合語法仍可接受》，《香港文匯報》2023-04-26
https://www.wenweipo.com/epaper/view/newsDetail/1650922469801988096.html

| 例子 | 该文的判定 | 依据 |
|---|---|---|
| 他在早上吃了點麵包 | 不算病句，但**"在"多余** | 汉语时间名词不需要介词引介，可直接放句首或动词前 |
| **在**早上下了一場雨 | **"不折不扣的病句"** | "早上"被降成介宾，介宾短语不能作主语，**主语残缺** |
| 学生们应该努力读书（译自 Students should study hard） | **不是病句，只能称"欧化句"** | 汉语无数变化，复数意义明确时不必用"们" |
| 這咖啡店有很多貓**們** | 除非拟人，加"们"就有问题 | 同上 |

这一栏给本技能两点东西。

**一是一条硬判据**：介词框架最严重的后果不是累赘，是**吞掉主语**。`symptoms.md` C 节与 B 节都列了"在……的情况下"，但过去只说它冗长。陈美亚的例子说明：一旦时间或条件名词被装进介宾结构，那句就没有主语了——这是语法问题，不是语体问题。见到"在＋时间名词＋动词"，先查主语还在不在。

**二是交付措辞要改。** 陈美亚把"病句"与"欧化句"分开，是有用处的说法策略：对作者讲"这一处是语体问题，不是语法错误"，比判它"写错了"更容易被接受，也更准确——因为**能站住的欧化句子确实大多不违反语法，只是不经济**。本技能的 `SKILL.md` 早就说欧化轴"不判对错"，与此完全一致，落地的做法就是把措辞从"这是病句"改成"这句合语法，但白多花了两层壳"。

## 4. 英译汉的畸形欧化八类（期刊论文全文，一手）

来源：闫易乾、韩孟奇《翻译工作者如何识别汉语的畸形欧化》，《上海理工大学学报（社会科学版）》2019 年第 41 卷第 3 期，224–229 页（收稿 2017-09-09），期刊官网全文
https://jss.usst.edu.cn/html/2019/3/20190305.htm
该文把畸形欧化分八类：代词增多、主语凸显、"当……的时候"、联结词"和"、句子延长、状语增多、固定词组直译、判断句。

⚠️ **这批全部是已出版译文的译例，不是中国人自撰的句子。** 用途只有两个：说明这些"型"真实存在，以及示范改法。**不要当自撰病例引用，更不要拿去证明"中国作者都这么写"。**

| 译例（原译） | 该文给出的改译 | 型 |
|---|---|---|
| 曾胡译《谈人之将老》：两句里 5 个"她"、4 个"他"，该文评"读来让人几乎喘不过气" | 删多余代词，作"她一守寡，便投身于妇女的高等教育事业了" | 代词过量 |
| 冰心译《吉檀迦利》"我忘记了旅行**底**目的，我无抵抗地把我的心灵交给……" | "我忘记了旅行的目的，无抵抗地把心灵交给阴影与歌曲的迷宫" | 主语凸显＋"底"字（1920–30 年代译例，可作历时起点） |
| 郑振铎译《飞鸟集》"**当**我们是大为谦卑**的时候**，便是我们最近于伟大的时候" | "人越是谦卑，便越接近于伟大" | `当……的时候`＋判断句包装 |
| 曾胡译："那些有强烈的不受个人感情影响的爱好、行为适度的人，是最容易成功地度过老年期的" | 拆成条件小句："如果人们有强烈的兴趣爱好，又不受个人感情影响，并且行为恰当适度，成功度过老年期绝非难事" | **多层"的"长定语**——注意该文用的是"拆成小句"而不是"压成短句" |
| 董乐山、孟军译《伤残的树》"约瑟夫在**巴结地**工作了二十四年以后就**被**辞退了" | 该文指出"巴结地工作"不合汉语习惯，是把介词短语转成了副词＋动词 | "地"状语滥用＋被动 |
| 张荣超译《秘密花园》"**直到**我发话，他们可以回去工作" | 该文："地道汉语应该是：『没有我的同意，他们谁都不许回去工作』" | until 直译的时限框架 |
| 张晨光译《汤姆叔叔的小屋》"那女人对这些冷讥热讽的话毫不理会……脸上依然**带着那种**怒气冲冲、目空一切**的表情**" | "那女人毫不理会冷嘲热讽，继续往前走，一副怒气冲冲、目中无人的样子" | `对……`框架＋"带着……的"直译 |
| 子达译《人性的优点》"她发现，即使是站在厨房的水池前洗碗，也**成了一件使她开心不已的事情**" | "她发现，在厨房的水池前洗碗都令她开心不已" | 判断句包装＋"使" |

该文的第 5 例值得单独说一句：处理超长定语时，它选的是**把定语拆成条件小句**，而不是把句子削短。这与 `SKILL.md` 第六节"拆的是嵌套深度，不是字数"完全对得上，可以给那条一个外部依据。

另一条只能存疑：该文转引"梦之"的话"英语句子结构呈树状……汉语句子结构呈竹节状，逐节展开"。**"梦之"疑即王力笔名，但归属与出处未核到原书，引用须标 ▽ 转引存疑。**

## 5. 历时与量化证据：欧化在扩张，而且**正式语体最深**

这一节回答一个常被拿来堵嘴的问题："去欧化是不是逆历史潮流？"

- **△ 仅目录与内容简介**：贺阳《现代汉语欧化语法现象研究》，商务印书馆 2008.12，309 页，ISBN 9787100060660。目录含第 2 章"动词、形容词的欧化现象"（2.1 以谓词为中心语的定中结构的复苏和发展、2.2「N 的 V」、2.3「NV」、2.4「PP 的 V」）、第 3 章代词的欧化、**第 8 章「被」字句的发展**（8.1 语义色彩的变化；8.2 使用频率的增长，下分"『被』字句使用频率的考察"与"增长的原因"）、第 9 章语序的欧化（9.1 并列连词"和"的语序变化、9.2 主从复句的语序变化）。内容简介转述其结论：欧化相对而言是"突发"而非"渐变"；**"欧化现象"限于书面语，而书面语的欧化又受语体制约，正式语体受影响比较明显，接近口语的文学作品影响较少**；作者"引用历史文献，进行了详尽的统计分析"。**数据表页未读到。**
  http://www.queshu.com/book/15259747/trends
- **○ 一手摘要页**：連華（Hua Lien）《現代漢語歐化後的「被」字句研究與教學建議》，国立暨南国际大学华语文教学研究所硕士论文，指导教授何淑贞，2013，DOI 10.6837/NCNU.2013.00029。以 2012 年两岸书面与口语语料观察"欧化前—欧化时期—现代"的演进，结论：**「被」字句历时发展最大的特征是中性义及肯定义"被"字句增加，造成否定义比例减少，两岸书面语及口语皆然。**（全文需借阅）
  https://www.airitilibrary.com/Article/Detail/U0020-0309201302255000
- **△ 机构新闻稿**：沈国威（浙江工商大学东亚研究院・日本研究中心特聘教授、关西大学名誉教授）《汉语的现代转型与欧化语法》，厦门大学中文系"名家讲坛"2024-11-08。要点：欧化语法研究以王力《中国现代语法》《中国语法理论》为起点；"语法的欧化即词语的复音化"，多数复音词与英译有关；并提出**"欧化语法从东方来"**——复音词多源自英华字典、英和辞典，经日本转手。方法路径：日本词汇频次可用日本国立国会图书馆 Ngram Viewer，国内可用 BCC 与 CCL 语料库（原稿作"BBC 数据库和北大数据库"，应为讹）。**这是"哪里能量化"的路线图，本身不是数据。**
  https://chinese.xmu.edu.cn/info/1481/33751.htm

**推论（这一条要写在明处，它反过来加强主轴）**：欧化确实在扩张，而且**受冲击最深的正是正式语体**。所以"这是公文、这是学术文体，需要庄重"**不能**当豁免欧化的理由——正式语体恰恰是欧化堆积最厚的地方。想引用这段数据，请注意证据强度：贺阳只核到目录与简介，連華只核到摘要，**都没有读到数据表**。结论可信，具体百分比不可引用。

## 6. 反面意见，以及它们真正攻击的位置

分类结论先给：**本次核到的反对意见里，没有一条正面推翻"恶性欧化真实存在、应当清理"。** 它们各自攻的是别的东西，因此各有一条对应的吸收方式。

| 意见 | 矛头指向 | 本技能怎么办 |
|---|---|---|
| △ 陈思和《欧化语言未必不好》（原载《学术月刊》2016 年第 7 期；《文摘报》2016-08-11 第 06 版转载）："文章写得拗里拗口不通顺当然不足取，但如果作者自己确实是那么感受和思考问题的，也未必就是坏事"；"非常流畅的文章也可能是作者的思想本来就很浅" | **以流畅简洁为唯一美学标准**这件事。注意他先承认"不通顺不足取"，所以不是替翻译腔辩护 | 吸收为一条让步：**判据在"作者确实这么思考"处要让位**。这与 `SKILL.md` 的履职判据同源，也与史铁生"熟练于文学是末路"（`norms.md` 2.7）一致。改稿时遇到"绕"的句子，先问它在不在表达一个复杂的东西，再问它通不通 |
| △ 陈美亚（见第 3 节）：欧化句"符合语法规则，那并不能视为病句" | **"病句"这个标签** | 吸收为交付措辞：说"语体问题"不说"语法错误"（`SKILL.md` 第九节的诊断要点按此写） |

**还有两条直接可用作判据的**

- △ 朱光潜（据《朱光潜全集》第四卷，安徽教育出版社 1987，转引自维基条目）："**如果一句话依中文习惯可以说得同样精确有力，我们就绝对不能欧化它；欧化须在表现上有绝对必要时才可采用**"；并说语文逐渐生长，"这一代欧化得轻微一点，下一代习惯成自然"。
  **这条是反开脱五问缺的那个准入条件，可直接并进去**：想保留一处欧化，就得说明按中文习惯的说法为什么表达不出同样的精度和力度。说明不了，就改。它比"承载不承载信息"更严，也更可操作。已补进 `craft.md` 第 4 节。
- ◎ 鲁迅《玩笑只當牠玩笑（上）》："歐化文法的侵入中國白話中的大原因，並非因爲好奇，乃是爲了必要"；"要說得精密，固有的白话不够用，便只得採些外國的句法。比較的難懂……但補這缺點的是精密。"
  **演进尺度的一手依据**：难懂可以用精密来抵，但必须先真的更精密。**没有换来精密的难懂，两头都亏**，那才是本技能要清的。

## 7. 本轮新增的三条判据（已回写到各文件）

1. **可替换性测试**（朱光潜）——按中文习惯能否说得同样精确有力。能，就必须改。进 `craft.md` 第 4 节。
2. **音节配双**（ILC"二二节奏"、陈洁珊双音节例）——正式感来自双音节配双音节、二二成对。这是外部机构给的成文理由，替掉了我方原来的断言。进 `craft.md` 第 2 节与 `norms.md` 3.1。
3. **歧义优先于雅观**（"全港教育研讨会"vs"全港性教育研讨会"、"政府的施政方案被市民支持"）——后缀与被动有时付的不是文体代价，是误读代价。判据从"读着别扭"升级为"能不能被读成第二种意思"。进 `symptoms.md` B 节。

另有一条操作判据来自陈美亚：**"在＋时间名词＋动词"要先查主语是否被吞掉**——这是语法后果，不是语体偏好。
