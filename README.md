# normalize-chinese-prose

让大模型在起草或修改中文时，遵循成熟写作者的习惯下笔。

适用于 Claude Code、OpenAI Codex、DeepSeek Harness 等支持 `agents/skills` 规范的 Agent 环境。

---

## 核心理念

### 1. 去欧化（通、简、洁）
现代书面语受外语翻译腔侵蚀严重，大模型生成时尤为多发。本技能重点治理以下几类结构：
- **多层“的”长定语**：中心词前堆叠两层以上不同维度的限定，导致主干模糊；
- **万能动词搭配抽象名词**：“对……进行分析”、“作出……贡献”、“开展……工作”，用空转框架替代动词本身；
- **非必要被动句**：滥用“被认为”、“被广泛应用于”，削弱中文主动推进的语感；
- **从句语序倒置**：直译外语从句，机械套用“当……的时候”、“在……的情况下”。

### 2. 去 AI 味（常态表达）
打破模型经过对齐训练后形成的程式化指纹：
- **防御性负描述与过度对冲**：虚设靶子，习惯性先退三步立界（如“本方案不追求……也不试图……而是……”）。处理口诀为：**非必要不立反面，直接给出正面断言**；
- **从属说明喧宾夺主**：对非核心的除外条件或补充说明反复自辩。处理原则为：**只给决策和理解依据，说清理由即止**；
- **相邻句骨架同款**：连续小句在逗号位置、成分顺序、收尾方式上高度同构；
- **篇章套路**：总分总模板、现状—问题—对策三段式、冒号列表撑版面、结尾强行升华。

### 3. 履职先于语体
判据分两层，文体功能优先于修辞优化：**先问这句话在文体里是否履职，再问它像不像好中文。**
- 合同条款的防御性表述不是同义反复；
- 技术规范和法律条文的长限定是在定义义务标的，不轻易拆散；
- 学术论述的克制是必要的严谨性。

第一层成立就不轻易动。“判定不改”是正当结论；从零起草时同样以文体功能为第一准则。

## 理论与实证依据

本技能的判据建立在语言学论述、语篇实证研究与国家标准之上：

### 1. 汉语修辞与语法学说
- **余光中**《怎样改进英式中文？——论中文的常态与变态》（1987）：提供可替换性原则、一“的”一义、万能动词替换以及双音节二二节奏等具体分析方法。
- **王力**《中国现代语法》：界定欧化语法现象主要发生在书面语层面，指出汉语缺乏西方语言的多层从句结构，依托流水小句推进。
- **吕叔湘、朱德熙**：关于汉语流水句、意合特征与现代汉语规范的论述，以社会普遍承认为语言沉淀与演进的界限。
- **贺阳**《现代汉语欧化语法现象研究》：指出正式语体受欧化语法影响最为深远，明确了公文与学术文体同样需要注重语体通洁。

### 2. 人机生成语篇实证研究
- **杨林秀、平嘉鹏**（《当代修辞学》2024 年第 6 期）：基于元话语分析框架，揭示大模型在学术语篇中态度标记匮乏与对冲语过度使用现象，以及程式化否定结构（Negative Parallelism）对直接断言的削弱。
- **朱君辉、王萌岩等**（《中文信息学报》）：揭示大模型文本存在显著的“统计均质化”与“模式化对称支架”，语法树扁平对称，反映了自回归采样处于集中安全区的特征。
- **吴继峰、胡韧奋、彭一平**（《语言文字应用》2025 年第 4 期）：实证分析学术汉语中大模型的句法树层级与依存特征，指出模型文本具有句法树偏浅、表层形式化衔接偏多的特点。
- **崔希亮、赵霞**（《当代修辞学》2024 年第 3 期）：明确将大模型语言问题界定为修辞学层面的交际与篇章构建问题。

### 3. 法规与标准分层
- **法律强制层**：《中华人民共和国国家通用语言文字法》（2025 年修订，2026-01-01 施行），规范出版物、信息技术产品及公共平台的文字使用与外文加注义务；
- **推荐性标准层**：GB/T 15834《标点符号用法》、GB/T 15835《出版物上数字用法》、GF 1001《第一批异形词整理表》；
- **语体修辞层**：句法与修辞以通顺、简明、自然为标准，不以法规越界裁定。

## 基本架构

技能由主入口与 8 个专业参考模块构成：

```text
normalize-chinese-prose/
├── SKILL.md            # 主入口：立场、三大守恒红线、七步撰写/改写工作流、四项读法、七大动作
├── LICENSE             # MIT 许可证
├── README.md           # 使用说明
└── references/
    ├── craft.md        # 动作库详解、九大文本族特性、反开脱五问与 12 条反例警戒
    ├── models.md       # 正面特征库、虚字手感、句式库、正面界定表、正向自查八问与分族豁免
    ├── norms.md        # 理论依据：现行法律国标条款、学者学说、人机语言特征实证文献
    ├── symptoms.md     # 症状速查表（结构层、句法层、字法层、词层、文字层）
    ├── cases.md        # 34 组带一手文献出处的病例对照与改法理由
    ├── examples.md     # 13 类文体整段示范（技术报告、公文、学术论文、合同等）
    ├── samples.md      # 26 段 1949 年后真实发表范文的实测分析
    └── corpus.md       # 语料库总目与登记册（逐条标定四级置信度 ◎○△▽）
```

### 核心方法概览
- **七大动作**：拆（后置长定语）、换（本字动词）、删（空框架与虚字）、并（错开同款骨架）、主（还原主动）、缀（一“的”一义）、正（正面界定替代负描述）。
- **四项读法**：复述测试（查有效信息）、朗读测试（查自然起伏）、具体项测试（查可核验事实）、假想敌测试（查防御性表述与过度阐释）。
- **三大守恒红线**：
  1. 信息守恒：数字、单位、专名、法律情态词（应当/不得）一个不丢；
  2. 证据强度守恒：推测不升格为必然，可能不改写成确定；
  3. 不添事实：原稿未提供的数据向作者索取，严禁擅自编造。

## 安装与使用

克隆到本地通用或特定 Agent 技能目录即可：

```bash
# 通用 Agent 技能目录
git clone https://github.com/Zessi-C/normalize-chinese-prose.git ~/.agents/skills/normalize-chinese-prose

# 或 Qoder 工具目录
git clone https://github.com/Zessi-C/normalize-chinese-prose.git ~/.qoder-cn/skills/normalize-chinese-prose
```

支持该约定的 Agent 会自动加载。在对话中要求“写一段方案”、“起草公文”、“去 AI 味”、“顺一下中文”或“写得像行家一点”时，直接生效。
