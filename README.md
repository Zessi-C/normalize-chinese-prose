# normalize-chinese-prose

让 AI 在写中文或改中文时，能像个真正有经验的写作者那样下笔。

适用环境：Claude Code、OpenAI Codex、DeepSeek Harness 等支持 `agents/skills` 约定的 Agent。

---

## 为什么做这个

用大模型写中文或改中文，最容易掉进两个坑：

1. **满篇翻译腔与欧化句法**：滥用多层“的”长定语、万能动词包装（“对……进行全面分析”、“作出重要贡献”）、非必要被动句、把动词强行包装成抽象名词。
2. **典型的 AI 味与假想敌对冲**：逢陈述必先退三步立界（“本方案不追求全面重构，也不试图替代现有系统，而是聚焦于……”、“这并不意味着……更不代表……”），再配上机械的总分总结构与排比句。

市面上常见的“去 AI 味”方案大多只给负向词表，让模型无脑切短句、删连接词、刷低检测率。结果往往是病症清除了，文章却退化成缺乏信息密度的电报体碎句，或者换套文雅的说辞把空话再说一遍。更严重的是，盲目套用规则会把合同的防御性冗余当同义反复切掉，把法律和学术的长限定切散，导致语义和责任标的彻底变质。

这套技能的目标不是“把毛病清零”，而是让模型在**落笔起草或修改时，补齐成熟写作者的经验感**。

---

## 怎么解决的

### 1. 履职先于语体
判据分两层，顺序不能颠倒：
- **先问这句在这个文体里履职了没有**：定义义务标的没有？标明证据强度没有？保住角色声音没有？给出做决定所需的信息没有？
- **再问它像不像常态中文**。

第一层过了就别轻易动。合同条款的严密防御、技术规范的前置限定、学术讨论的审慎，都是文体本身的职业美德。“判定不改”是完全正当的交付，不是没干活。

### 2. 三条判据轴
- **欧化轴**：依据王力、余光中、吕叔湘、朱德熙一系的论述，重点解决长定语嵌套、万能动词、抽象名词作主语和英式从句语序。
- **AI 味轴**：针对大模型在 RLHF 对齐后习得的“过度对冲与避险”（否定平行结构），严守**“非必要不立反面，直接给出正面断言”**。同时拆解相邻句句法骨架同构（逗号、成分与收尾连续复现）。
- **演进尺度**：现代汉语吸收的外语语法（如被字句的中性用法、代词分化、`-性/-化` 术语后缀）已成为全民规范的，一律不改。

### 3. 正向牵引与年代分水岭
- 负向清单只能防错，必须配上正向句式：起句怎么开门见山、事实如何推进、转折的四种硬度、判断的三种强度。
- **样板年代隔离**：五四时期的名家多为自觉的欧化实验者（如鲁迅“宁可忠实而不顺”），其主张可作判据，原句不能拿来当常态中文的节奏样板。可供借鉴节奏的文本，全部取自 1949 年以后（实测集中在 1975 至 2026 年）真实发表的成熟书面语。

### 4. 彻底剔除伪指标
- 不设通过线、不数密度、不跑外部打分脚本。
- **撤销“句长方差”伪判据**：实测显示句长分布与段落厚薄根本测不出人机差异，人类写作同样大量使用长从句。真正的人机差异在于**相邻句句法骨架的同构复现**（约 2.0 倍差异）。

## 核心动作速览

七个核心改写动作：

- **拆**：前置长定语搬到句后，按流水小句自然推进。
- **换**：万能动词＋抽象名词换回本字动词（“进行分析”→“分析”）。
- **删**：剔除不承载信息的框架词与虚字（“关于……的问题”、“当……的时候”）。
- **并**：错开相邻句同款骨架，排比支架打散成常态叙事。
- **主**：非必要被动句还原为主动句或无标记句。
- **缀**：一“的”一义，限定落回原位。
- **正**：**正面界定替代负描述**。删去凭空树立的否定假想敌（“不追求……也不试图……而是……”直接改成“聚焦于……”）。

三大不变量红线：
1. **信息守恒**：数字、单位、专有名词、技术符号、法律情态词（应当/不得）一个不丢。
2. **证据强度守恒**：推测不升格为必然，可能不改写成确定。
3. **严禁编造**：原稿未提供的主体、数据与细节，列入存疑清单向作者确认，严禁脑补。

所有规则与语料均收录在 `references/` 目录下：

```text
normalize-chinese-prose/
├── SKILL.md            # 技能主入口（立场、七步工作流、四项读法、七大动作与交付格式）
├── LICENSE             # MIT 开源协议
├── README.md           # 使用说明
└── references/
    ├── craft.md        # 动作库详解、九大文本族特性、反开脱五问与 12 条反例警戒
    ├── models.md       # 正面特征库、虚字手感、句式库、正面界定表与正向七问
    ├── norms.md        # 理论依据：现行语言文字法与国标分层、学界论述、AI 味实证研究
    ├── symptoms.md     # 症状速查表与已撤销伪判据清单
    ├── cases.md        # 34 组带一手文献出处的病例对照与改法理由
    ├── examples.md     # 13 类文本整段改写示范（技术报告、公文、学术论文、合同等）
    ├── samples.md      # 26 段 1949 年后真实发表范文的实测分析
    └── corpus.md       # 语料库总目与登记册（严格分级管理）
```

## 安装方式

克隆到本地通用或特定 Agent 技能目录即可：

```bash
# 通用 Agent 技能目录
git clone https://github.com/Zessi-C/normalize-chinese-prose.git ~/.agents/skills/normalize-chinese-prose

# 或 Qoder 工具目录
git clone https://github.com/Zessi-C/normalize-chinese-prose.git ~/.qoder-cn/skills/normalize-chinese-prose
```

克隆完成后，支持该约定的 Agent 会自动加载。在对话中要求“写一段方案”、“起草公文”、“去 AI 味”、“顺一下中文”或“写得像行家一点”时，即可直接生效。
