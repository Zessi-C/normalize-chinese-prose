# normalize-chinese-prose

让 AI 在写中文或改中文时，能像个真正有经验的写作者那样下笔。

适用环境：Claude Code、OpenAI Codex、DeepSeek Harness 等支持 `agents/skills` 约定的 Agent。

---

## 一、设计理念：去欧化与去 AI 味

中文书面写作的核心在于信息密度、推进节奏与文体功能。但在大语言模型的中文生成中，普遍存在两类影响阅读体验的问题：

### 1. 去欧化（追求通、简、洁）
清理不承载有效信息、增加阅读负担的翻译腔结构：
- **多层“的”长定语**：中心词前堆叠多层不同维度的修饰，导致主干模糊；
- **虚动词搭配抽象名词**：“对……进行分析”、“作出……贡献”、“开展……工作”，用空转框架替代具体动词；
- **非必要被动句**：滥用“被认为”、“被广泛应用于”，削弱中文的主动表达习惯；
- **从句语序倒置**：直译外语从句结构（如“当……的时候”、“在……的情况下”）。

### 2. 去 AI 味（追求常态表达）
打破模型生成时常见的程式化痕迹：
- **对称否定与过度对冲**：频繁使用“不仅没有……反而……”、“不是……而是……”等平衡支架；
- **相邻句句法骨架同款**：连续小句在逗号位置、成分顺序、收尾方式上高度同构，呈现类似填表的机械感；
- **套路化篇章框架**：依赖总分总、现状—问题—对策、大量冒号列表支撑版面，或在结尾强行总结升华。

### 3. 履职先于语体
文体功能优先于修辞优化：**先问这句话在文体里是否履职，再问它像不像好中文。**
- 合同条款的防御性表述不是同义反复；
- 技术规范和法律条文的长限定承载义务标的，不轻易拆散；
- 学术论述的克制是必要的严谨性。

只要第一层成立，就不轻易改动。“判定不改”是正当结论；从零撰写时同样以文体功能为第一准则。

## 二、理论依据与学术观点

本技能的判据建立在汉语语言学、话语分析与现代审校规范之上：

### 1. 汉语修辞与语法学说
- **余光中**《怎样改进英式中文？——论中文的常态与变态》（1987）：提供可替换性原则、一“的”一义、万能动词替换以及双音节二二节奏等具体分析方法。
- **王力**《中国现代语法》：界定欧化语法现象的书面语边界，强调汉语以流水小句为核心的推进方式。
- **吕叔湘、朱德熙**：关于汉语流水句、意合特征与现代汉语规范的论述，以社会普遍承认为语言演进与沉淀的判定尺度。
- **贺阳**《现代汉语欧化语法现象研究》：指出正式语体受欧化语法影响最为深远，明确了正式文体同样需要注重语体通洁。

### 2. 人机生成语篇实证研究
- **杨林秀、平嘉鹏**（《当代修辞学》2024 年第 6 期）：通过元话语分析框架，揭示大模型在学术语篇中态度标记匮乏与对冲语过度使用现象，以及程式化否定结构对论述直接性的削弱。
- **朱君辉、王萌岩等**（《中文信息学报》）：分析大模型文本的统计均质化特征，揭示自回归采样倾向于生成语法对称、结构均质文本的机制。
- **吴继峰、胡韧奋、彭一平**（《语言文字应用》2025 年第 4 期）：实证分析学术汉语中大模型的句法树层级与依存特征，指出模型文本具有句法树偏浅、表层形式化衔接偏多的特点。
- **崔希亮、赵霞**（《当代修辞学》2024 年第 3 期）：将大模型语言问题界定为修辞学层面的交际与篇章构建问题。

### 3. 现行法规与标准规范
- **法律强制层**：《中华人民共和国国家通用语言文字法》（2025 年修订，2026-01-01 施行），规范出版物、信息技术产品及公共平台的文字使用与外文加注义务。
- **推荐性标准层**：GB/T 15834《标点符号用法》、GB/T 15835《出版物上数字用法》、GF 1001《第一批异形词整理表》。
- **语体修辞层**：句法、修辞与语体以通顺、简明、自然为标准，不以法规替代语感裁定。

## 三、基本架构

技能由主入口与 8 个专业参考模块组成：

```text
normalize-chinese-prose/
├── SKILL.md            # 主入口：立场、三大守恒红线、七步工作流、四项读法、七大动作与交付格式
├── LICENSE             # MIT 许可证
├── README.md           # 说明文档
└── references/
    ├── craft.md        # 动作库详解、九大文本族、反开脱五问与 12 条反例警戒
    ├── models.md       # 正面特征库、虚字手感、句式库、正向自查七问与分族豁免
    ├── norms.md        # 理论依据：法规国标条款、学者学说、人机语言特征实证文献
    ├── symptoms.md     # 常见症状速查表（结构层、句法层、字法层、词层、文字层）
    ├── cases.md        # 34 组带文献出处的病例对照与改法理由
    ├── examples.md     # 13 类文本整段示范（技术报告、公文、学术论文、合同等）
    ├── samples.md      # 26 段 1949 年后真实发表范文的实测分析
    └── corpus.md       # 语料库总目与登记册（四级置信度 ◎○△▽ 标定）
```

### 核心方法概览
- **七大动作**：拆（后置长定语）、换（本字动词）、删（空框架与虚字）、并（错开同款骨架）、主（还原主动）、缀（一“的”一义）、正（正面界定）。
- **四项读法**：复述测试（查有效信息）、朗读测试（查自然起伏）、具体项测试（查可核验事实）、假想敌测试（查防御性表述）。
- **三大守恒红线**：信息守恒（数字、单位、专名、情态词不丢）、证据强度守恒（推测不升格为必然）、不添事实（未给出的数据向作者索取，不擅自编造）。

## 安装与使用

克隆到本地通用或特定 Agent 技能目录：

```bash
# 通用 Agent 技能目录
git clone https://github.com/Zessi-C/normalize-chinese-prose.git ~/.agents/skills/normalize-chinese-prose

# 或 Qoder 工具目录
git clone https://github.com/Zessi-C/normalize-chinese-prose.git ~/.qoder-cn/skills/normalize-chinese-prose
```

支持该约定的 Agent 会自动加载。在对话中要求“写一段方案”、“起草公文”、“去 AI 味”、“顺一下中文”或“写得像行家一点”时，直接生效。
