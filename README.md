# normalize-chinese-prose

把任何类型的简体中文文本改成像有经验的写作者写的。

一个为 AI Agent（Claude Code、OpenAI Codex、DeepSeek Harness 等遵循 `agents/skills` 规范的环境）设计的专业中文语体优化与去“AI 味”规范技能。

不同于市面上常见的“给负向禁用词表”、“机械切短句”、“盲目刷低检测率”的工具，本技能建立在**“履职先于语体、正向生成牵引、三维学术证据、防御性负描述拦截”**的完整语言学与出版审校体系之上。

---

## 核心设计理念

### 1. 履职先于语体（功能优先于修辞）
**“目标不是没有毛病，是像有经验的写作者写的。”**  
每种文体都有其职业美德，而这些美德在通用症状表里往往长得像病症：
- **合同的防御性冗余**像同义反复；
- **法律与技术规范的长限定**像欧化长句；
- **小说的刻意含蓄**像零具体；
- **学术论述的克制**像无判断落点；
- **译文的欧化句法**本来就是其母语。

**判据严格分两层：**  
1. **这句话在这个文体里履职了吗？**（定义了义务标的没有？标定了证据强度没有？保住了人物声音没有？给出了读者做决定所需的信息没有？）
2. **它像不像常态中文？**  
第一层过了就别动，哪怕第二层看着别扭。**“判定不改”是一个正当结论，不是没干活。**

### 2. 三条判据轴
- **欧化轴（通／简／洁）**：以余光中、王力、吕叔湘、朱德熙一系的语言学论述为基础，治理多层“的”长定语、万能动词包装（`对……进行`、`作出……`）、非必要被动、名词化泛滥等英语/日语侵入句法。
- **AI 味轴（结构同构与假想敌对冲）**：治理总分总模板、现状—问题—对策三段式、冒号列表撑版面、相邻句句法骨架同款复现、**防御性负描述与假想敌对冲**（`本方案不追求……也不试图……而是……`）。
- **演进尺度（现代汉语沉淀界限）**：五四以来的白话文演进已吸收了部分外来语法（中性被字句、`-性/-化` 术语后缀、关联复句）。优秀的当代作者也在用、读者不别扭的沉淀句式，不强行动改。

### 3. 正面牵引与年代分水岭
- **光排除不够**：负向清单只能防错，不能指导生成。技能内建**八大正面特征**、**虚字手感（了/的/当/被/之其而）**、**七类句式库（起句/推进/转折/列举/判断/让步/收尾）**。
- **样板年代隔离**：1920–1930 年代五四名家多为自觉的欧化实验者（如鲁迅“宁可忠实而不顺”），其主张可作“判据”，但原句不作“样板”；可照搬节奏的原句只取 **1949 年以后（实测集中在 1975–2026 年）**成熟书面汉语，彻底排除理论内耗。

### 4. 彻底剔除伪科学指标
- **撤销“句长方差/长短齐整”**：外部人机对照实证表明，字数和段落厚薄的分布在统计学上测不出人机差异。盲目切短句只会落入大模型原本就偏浅的句法分布。
- **改打“句法骨架同款”**：真正测得出显著差异（约 2.0 倍）的是**相邻句的句法同构**（逗号位置相同、成分顺序相同、收尾方式连着复现）。
- **零打分、不算密度**：坚决不设硬性打分工具，可读性交还给真实语感（复述测试、朗读测试、假想敌测试）。

## 针对“防御性负描述（假想敌对冲）”的专项拦截

大语言模型（LLM）在经过安全微调（RLHF）后，普遍习得了一种**无意识的防御性避险习惯**——不管读者是否有误解，逢观点必先退三步（学术界称之为**否定平行结构 Negative Parallelism** 或**元话语过度对冲 Over-hedging**）：

> ❌ **常见 AI 负描述病态**：  
> `本方案不进行全面的系统重构，也不试图替代现有流程，而是聚焦于三个核心接口的优化。`  
> `这并不意味着旧架构存在根本缺陷，更不代表前期工作白费，而是新业务提出的更高要求。`  
> `新设计不仅没有增加开发负担，反而缩短了交付周期。`

本技能在动作库确立核心动作 **“正”（正面界定替代负描述）**：
- **核心口诀**：**非必要不立反面，直接给出正面断言。**
- ✔️ **改后常态中文**：  
  `本方案聚焦优化三个核心接口。`（直接删掉两个空转假想敌，让正向动作当家）  
  `旧架构在千级并发下运行良好；本次升级旨在支持万级并发。`（避险退缩换成客观事实对比）  
  `新设计缩短了交付周期，且未增加开发负担。`（消除表演感，正面说收益）
- ⚠️ **严格保留法律/技术除外线**：法规合同中的法定除外条款（`甲方不承担……责任`）与技术硬边界（`该接口不支持异步回调`）属于标的界定，严格保留。

## 安装与使用

### 安装到通用 Agent 技能目录

支持克隆到本地用户级 skills 目录：

```bash
# 通用 Agent 目录
git clone https://github.com/Zessi-C/normalize-chinese-prose.git ~/.agents/skills/normalize-chinese-prose

# 或特定 Agent 工具目录（如 Qoder）
git clone https://github.com/Zessi-C/normalize-chinese-prose.git ~/.qoder-cn/skills/normalize-chinese-prose
```

### 触发方式

在对话中输入如下意图即可自动或显式触发：
- “去 AI 味”、“别太翻译腔”、“不像人写的”
- “太官方 / 太欧化”、“规范化这段中文”、“顺一下中文”
- “写得像行家一点 / 像有经验的写作者”
- 或在要求编辑公文、报告、论文摘要、技术文档、README、新闻稿、随笔、合同条款时调用。

## 边界与声明

1. **信息守恒**：改写严禁丢失原稿中的数字、参数、代码符号、专有名词、责任主体与引文。
2. **证据强度守恒**：`可能/推测` 严禁在改写中擅自升格为 `证明/必然`。
3. **严禁无中生有**：原稿缺失的主体、数据与依据，进“存疑清单”向作者索取，严禁大模型擅自“脑补”细节来换取流畅。
4. **不承诺降低 AIGC 商业检测率**：市面上的商业检测器本质是困惑度黑盒或营销产物，本技能旨在提升文本在真人读者面前的经验感与信服力，不以任何检测器分数为验收标准。
